# Blog LinkedIn Teaser

Use this documentation-only workflow to draft LinkedIn teaser copy for a blog post.

## Inputs

- Use the post draft, published post, title, excerpt, or notes the user provides.
- If the user provides a file path, read the file before drafting the teaser.
- If the post has front matter, use the title, excerpt, and tags as context.
- Read `STYLE.md` if available and preserve the author's direct, practical tone.

## Drafting Guidance

Write one LinkedIn teaser.

- Keep it short: 3-5 sentences.
- Hook the reader with the post's central tension, practical claim, or useful question.
- Create interest without summarizing every point in the post.
- Avoid glib, joke-like, cute, or hype-driven phrasing.
- Do not use hashtags unless the user asks for them.
- Do not use emojis.
- Include a placeholder link: `[Link to blog post]`.

## Final Response

Return only the draft LinkedIn teaser unless the user asks for options or explanation.
